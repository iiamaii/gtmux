# 인터페이스 규칙

기존 워크스페이스의 조밀한 컨트롤, 시스템 글꼴, 간격, 라이트·다크 색상 토큰을
사용합니다. 설정은 사용자가 이해하는 말로 변경 결과를 설명합니다.

## 켜기·끄기 설정

지속되는 on/off 설정은 슬라이드 스위치로 표시합니다. 트랙은 28 × 16 px,
손잡이는 12 px이며 워크스페이스에서는 기존 스위치 컴포넌트를 사용합니다.
관리자의 동등한 컨트롤에는 `role="switch"`, 접근 가능한 레이블, 명확한 키보드
포커스와 모션 감소 지원을 적용합니다. 내부 입력 요소로 체크박스를 사용하더라도
스타일 없는 사각 체크박스로 표시하지 않습니다.

## 상태와 확인

시작 중·실행 중·종료 중·실패 상태를 명시합니다. 요청 진행 중에는 충돌하는
작업을 비활성화합니다. 포트 충돌과 쓰기 실패는 원인을 표시하고 다른 설정을
조용히 덮어쓰지 않습니다.

서버 중지·재시작은 터미널 프로그램을 종료합니다. 확인 버튼 옆에서 이를 설명하고
저장된 레이아웃을 보존하며 로그에 인증 정보를 남기지 않습니다. 백그라운드 실행은
선택 사항이며 접근 가능한 트레이 제어를 유지해야 합니다.

## 검토

라이트·다크 테마, 키보드 탐색, 좁은 창, 긴 경로, 오류와 빈 상태를 확인합니다.
Windows 경로도 선택·결합·복사·워크스페이스 상대 경로 변환 후 유효해야 합니다.

관리 화면은 워크스페이스의 원본 디자인 토큰을 가져오며 패키지에도 같은 CSS를 포함합니다. 실행 UI는 영어이고 현재 다국어 대상은 문서입니다. 브라우저 회귀 검사에서 슬라이드 스위치·700px 관리 창·밝은/어두운 테마·키보드 크기 조절·Activity 폭 복원을 확인합니다.

데스크톱 창·트레이·실행 파일·설치 프로그램에는 기존 gtmux 로고를 사용합니다. 패키지 아이콘은 워크스페이스의 `brand.png`를 그대로 복사한 `codebase/launcher/ui/icon.png`이며 `tray.png`는 32px favicon입니다. 서명 없는 Windows 확인용 빌드는 `signExecutable: false`로 서명만 생략합니다. `signAndEditExecutable: false`는 리소스 편집도 생략하여 Electron 기본 아이콘을 남기므로 사용하지 않습니다.

데스크톱 첫 설정 화면은 색상뿐 아니라 SettingsOverlay의 구조와 크기를 따릅니다. 제목 16px, 라벨 12px, 설명 11px, 입력·버튼 높이 32px, 설정 행의 세로 여백 14px와 간격 28px를 사용합니다. 설명과 조작은 좌우로 정렬하고 경로 입력과 좁은 화면은 위아래로 배치합니다. 워크스페이스 스위치 컴포넌트와 관리 화면은 별도 구현 대신 같은 `settings-controls.css`를 사용합니다.
