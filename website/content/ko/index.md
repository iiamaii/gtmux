# gtmux

gtmux는 터미널·파일·메모를 하나의 공간형 캔버스에 배치합니다. 세션은 작업 레이아웃을 저장하고, 터미널은 서버가 관리하는 실제 프로세스입니다.

## 시작 방법

- 서버 배포물 또는 데스크톱 앱을 [설치](install.html)합니다.
- [서버 관리](manager.html)에서 포트를 고르고 앱·브라우저·둘 다 중 접근 방식을 선택합니다.
- 관리형 프록시로 [외부 HTTPS 접속](external-access.html)을 준비합니다.
- [기여 방법](contributing.html)과 [아키텍처](architecture.html)를 확인합니다.

## 포함된 기능

세션별 브라우저 탭 제목, 터미널 Activity 표시 설정, TOML 설정 저장, 재접속 시 attach 소유권 보호, 데스크톱 서버 관리자와 다국어 문서를 제공합니다.

Activity는 관측된 출력과 명시적으로 보고된 에이전트 상태를 구분합니다. 출력이 조용해졌다는 사실만으로 응답 완료나 입력 대기를 확정할 수는 없습니다. 필요 없는 표시는 Settings에서 끌 수 있습니다.

## 미리보기 상태

Linux 로컬 환경에서 서버와 관리자를 검증합니다. Windows 빌드는 ConPTY 기반 네이티브 서버를 사용하며 WSL이 필요하지 않습니다. Windows 설치 파일의 업데이트와 재실행도 격리된 로컬 피드로 검증했습니다. release workflow는 플랫폼별 패키지를 빌드하며, macOS·ARM 실행 검증과 서명·공개 릴리스 배포는 출시 전 확인이 남아 있습니다. 실제 다운로드는 저장소의 release 발행 여부에 따라 달라집니다. 서명되지 않은 패키지는 OS 신뢰 확인 화면을 표시할 수 있습니다.

## 프로젝트 소개 페이지

사이트 루트는 영어 프로젝트 소개 페이지이며, 상단 로고는 현재 언어의 소개 페이지로 이동합니다. 문서는 `/en/`과 `/ko/`에 유지됩니다. 화면 캡처는 격리된 데모 워크스페이스와 합성 에이전트 훅 이벤트를 사용했으며, 실제 사용자 세션이나 실행 중인 에이전트를 촬영한 것이 아닙니다.
