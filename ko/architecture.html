프로세스 경계

Rust backend가 PTY·세션 레이아웃·attach lock을 소유합니다. Svelte 앱은 작업 화면을 표시하고 브라우저별 Appearance를 저장합니다. 선택적으로 사용하는 관리자는 서버 자식 프로세스 하나, 별도 로컬 제어 리스너와 선택한 Caddy 자식 프로세스를 소유합니다. Electron은 창과 트레이 수명을 담당하며 작업 화면의 웹 콘텐츠에 Node.js 권한을 제공하지 않습니다.

관리형 서버는 별도 TOML·Store·XDG 폴더를 사용합니다. public_origin을 명시하면 backend를 외부 인터페이스에 바인딩하지 않고도 cloud 인증 정책을 적용하는 loopback 프록시 배포가 가능합니다.

서버 API

엔드포인트 역할
GET /api/config 파일 내용·revision·저장값/실행값·재시작 상태 조회
POST /api/config/preview 저장하지 않고 일반 필드 수정 검증
PUT /api/config 재인증·revision 검사 후 원자적 저장
GET /api/server/status 실행 상태와 서버 전체 터미널·세션 수 조회
POST /api/shutdown 재인증 후 호스트에 종료 요청

기존 서버 인증 경계를 사용하며 소프트웨어 설치 권한은 제공하지 않습니다. 로컬 관리자 API는 별도 최초 접속 쿠키와 같은 출처 요청을 사용하고 프록시로 공개하지 않습니다.

Attach 소유권

운영체제 파일 락이 소유권의 기준입니다. lease 문구는 진단 정보이며 만료되어도 다른 프로세스의 락을 무시하지 않습니다. 서버 내부에서는 owner map·holder map·연결 등록의 락 순서를 고정합니다. 마지막 연결 generation 검사와 guard 해제를 하나의 보호 구간에서 수행합니다. 연결 없는 소유권은 단조 시계 기반 유휴 기간 후 정리하며 활성 소켓은 보호합니다.

내장 사용

HTTP 라이브러리는 호스트 프로세스를 종료하지 않습니다. 호스트가 설정 파일 편집과 종료 신호 수신을 명시적으로 연결하고, 연결 정리·PTY backend 종료·attach guard 해제를 수행합니다. CLI·데스크톱 앱·다른 호스트가 프로세스 소유권을 혼동하지 않고 같은 backend를 사용할 수 있습니다.
