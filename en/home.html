YOUR WORK, IN ONE WORKSPACE

Keep your terminals in context.

A spatial workspace for terminals, files and notes. Follow several tasks without losing the thread — in your browser or on your desktop.

01 / Workspace

A place for every task.

Arrange terminals alongside the files and notes that explain the work. Save the layout as a session and return with the context intact.

Know which terminal needs you.

Activity brings working, completed and needs-input states into the sidebar. Connect agent lifecycle hooks for explicit status, and choose which indicators appear in your browser tab.

Explore agent integrations →

02 / Desktop

Your server. Your controls.

Choose a workspace folder and port, then open the workspace in a browser, an app window, or both. Save settings with visible feedback and manage the server from one place.

Read the desktop guide →

Settings that stay with your server.

Edit supported server settings in the UI and save them to TOML. Reload external changes, review validation errors and keep track of settings that require a restart.

Documentation →

A clearer route to HTTPS.

Set up a managed Caddy proxy for a domain or IP address, or connect your own proxy. The setup explains certificate choices and the network access you still need to provide.
