External access

Prepare a dedicated HTTPS proxy or connect one you already manage. Your backend stays on this computer's loopback interface.

  1. Choose a domain or IP address
  2. Review certificate and network requirements
  3. Install, apply and verify

Off does not uninstall Caddy. Return to External access, turn this switch on, review your saved address and ports, then choose Apply and restart. The switch shows applied configuration; check Connection status for reachability.

Public ports 80 and 443 must reach these proxy ports. High local ports can be used behind your router's port forwarding. Router and firewall settings remain under your control.

      Trust this CA only on devices you control after checking its origin. Import the downloaded certificate using your operating system’s trusted certificate settings. gtmux does not install it automatically. Existing proxies must provide their own CA.

      Not configured

      The proxy renews certificates while it is running. A running process alone does not mean your public address is reachable. Verification checks the public HTTPS endpoint.

      Agent activity

      Connect lifecycle hooks to report working, completed and input-needed states in the terminal where the agent runs. Enable Terminal activity in workspace Settings → Appearance.

      

      Review and merge with existing hooks. These hooks only report state; they never approve tools or modify prompts. Restart the agent after setup. In Codex, review and trust the integration in /hooks. Agent versions differ: unavailable events stay unknown rather than being guessed. Completion hooks can precede another hook’s decision to continue a turn.
